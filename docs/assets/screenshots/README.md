# Demo Screenshot Guide

Only screenshots captured from the real local Vue operations console belong in this directory. Do not use generated mockups or synthetic UI images as product evidence.

Recommended files:

1. `01_dashboard.png` — real dashboard cards, decision/status distributions, and recent runs.
2. `02_agent_demo.png` — live POST-SSE Agent demo showing the execution timeline as events arrive.
3. `03_ticket_trace.png` — ticket detail with the sanitized ordered Agent trace.
4. `04_human_review.png` — human-review queue or empty state with its demo-only financial-action disclaimer.
5. `05_ticket_inbox.png` — filterable Ticket inbox backed by the Stage 6 API.

Before committing a screenshot, verify that it contains no API key, credential, personal information, browser account details, terminal output, or non-anonymous identifier. Demo customer/order/ticket IDs are acceptable. Crop browser chrome when it reveals unrelated personal data.
